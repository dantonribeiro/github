a distinção essencial

Duas ferramentas.
Um jeito melhor de trabalhar.

Uma vive na sua máquina. A outra conecta pessoas, projetos e possibilidades.

LOCAL01

Git

Sistema de controle de versão distribuído. Ele acompanha alterações, cria pontos de retorno e permite experimentar sem medo, mesmo offline.

REMOTO02

GitHub

Plataforma online que hospeda repositórios Git e adiciona colaboração: pull requests, revisão de código, issues e automações.

capítulo 02 · prática

Seu primeiro
repositório.

01

Configure

Identifique seus commits uma única vez no computador.

git config --global user.name "Seu nome"
git config --global user.email "voce@email.com"
02

Inicie

Transforme uma pasta em um projeto versionado.

mkdir meu-projeto
cd meu-projeto
git init
03

Publique

Conecte o local ao GitHub e envie sua história.

git remote add origin URL
git branch -M main
git push -u origin main
